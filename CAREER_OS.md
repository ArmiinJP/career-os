# CAREER OS

## Mission

Build a long-term, continuously improving Data Engineering career without waiting for a distant "ready" milestone.

## Principles

1. Capability-first, not tool-first.
2. Every month should visibly improve skill, evidence, or job readiness.
3. Practical experience and formal fundamentals must converge.
4. AI accelerates the system but does not own the system.
5. The user's career state must remain portable.
6. Use primary sources for important concepts.
7. Do not over-test or over-study low-priority topics.
8. Avoid over-architecture; justify complexity.
9. Preserve optionality for future business/product work.

## Core loops

### Learning loop
Source -> Understand -> Explain -> Challenge -> Practice -> Capture -> Recall -> Apply

### Career loop
Market -> Gap analysis -> Sprint -> Evidence -> Reassess -> Apply

### Architecture loop
Requirements -> Capacity -> Options -> Trade-offs -> Design -> Failure analysis -> Measure -> Simplify/Evolve

## Current north star

Senior/strong Senior Data Engineering capability with deep distributed/data systems and architecture skills, eventually moving toward Staff/Architect/technical leadership.
