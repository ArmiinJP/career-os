# ROADMAP

## North Star

Become a highly capable Data Engineer / Data Platform / Distributed Systems engineer with strong architecture and problem-solving ability, while continuously increasing job readiness and building the option to create a technical business later.

## Long horizon

The plan is intentionally compatible with a 5–10 year horizon. The unit of progress is the week/month, not the year.

## Operating model

Slow lane — long-term career capital:
- distributed systems
- databases/storage
- architecture
- reliability
- performance
- system design

Fast lane — immediate career leverage:
- interview preparation
- resume evidence
- real projects/benchmarks
- market analysis
- AI-assisted engineering

## Phase 1 — Consolidation

Goal: connect existing practical experience to formal concepts and build durable knowledge infrastructure.

Key areas:
- distributed systems
- database fundamentals
- Spark execution
- Kafka internals
- data modeling
- knowledge retention

## Phase 2 — Expansion

Key areas:
- PostgreSQL as a database-fundamentals lab
- object storage
- Parquet
- data lake / warehouse / lakehouse
- Iceberg
- orchestration (Airflow or equivalent)
- cloud foundations
- Kubernetes where relevant
- broader data ecosystem

## Phase 3 — Architecture

Key areas:
- system design
- capacity planning
- RPO/RTO
- reliability
- cost engineering
- architecture evolution
- consistency models
- consensus
- platform design

## Phase 4 — Leadership / Business

Key areas:
- technical leadership
- stakeholder communication
- product thinking
- architecture consulting
- building a product/business

## Month 1

Theme: **Distributed Data Systems + Architecture**

Week 1:
- partitioning vs replication
- storage/data system fundamentals linked to current experience
- capture first reusable knowledge entries

Week 2:
- consistency
- quorum
- network partitions
- failure
- CAP
- idempotency

Week 3:
- Kafka mental model: partitions, assignment, ordering, offsets, delivery
- Spark mental model: lazy evaluation, plans, stages, tasks, shuffle

Week 4:
- end-to-end architecture exercise
- explicit requirements/capacity/SLA/RPO/RTO/trade-offs
- write one architecture document

## Learning loop for each topic

1. Primary source
2. Read targeted section
3. Explain in own words
4. Discuss/challenge with AI
5. Solve a scenario
6. Capture a durable note
7. Schedule retrieval review
8. Produce evidence/experiment where useful

## Career loop

Every month:
- inspect real job postings
- map requirements to skill matrix
- identify newly closable gaps
- update resume evidence
- apply/test where appropriate

## Monthly success criteria

At least one of:
- deeper understanding of a concept
- new problem-solving capability
- new architecture capability
- new resume evidence
- more job roles realistically targetable

Prefer multiple outcomes from one project.
