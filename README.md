# Career OS — Portable Data Engineering Career System

## Quick start

If continuing with another AI:

1. Upload/read `AI_HANDOFF.md`.
2. Upload/read `CURRENT_STATE.md`.
3. Upload/read `ROADMAP.md` and `BASELINE.md` if needed.
4. Continue from the explicit `Immediate next action`.

## File map

- `AI_HANDOFF.md` — complete portable context
- `CURRENT_STATE.md` — latest snapshot
- `ROADMAP.md` — long-term and current roadmap
- `BASELINE.md` — baseline evidence and assessment
- `CAREER_OS.md` — principles and operating loops
- `DECISIONS.md` — strategic decisions
- `CHANGELOG.md` — history of meaningful state changes
- `UPDATE_PROTOCOL.md` — how to keep the system current
- `knowledge_base/` — durable knowledge
- `reviews/` — weekly/monthly reviews
- `evidence/` — resume/portfolio evidence

## Recommended storage

Use a private Git repository or a backed-up local folder. Do not rely only on chat history.
